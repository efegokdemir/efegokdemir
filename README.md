## What I build

- **[Shopify App ChangeGuard](https://github.com/efegokdemir/shopify-app-changeguard)** — an offline, read-only semantic reviewer for shopify.app*.toml changes. It provides a GitHub Action and CLI, redacts sensitive configuration values, and requires no Shopify credentials or network access.
- **[Shopify Upgrade Guard](https://github.com/efegokdemir/shopify-upgrade-guard)** — offline static analysis for documented Shopify platform and API upgrade risks, with deterministic scans and CI-oriented output.
